# كرت شبكة - لوحة التحكم

نسخة ويب مطابقة لواجهة التطبيق الذي أرسلته.

## طريقة التشغيل

1. افتح ملف `index.html` في المتصفح (Chrome أو Firefox).
2. أو ارفع المجلد على أي استضافة.

## المميزات الموجودة حالياً

- ✅ الواجهة الرئيسية مطابقة للصورة
- ✅ الإحصائيات (كروت متاحة / مستخدمة / عروض / باقات)
- ✅ إرسال يدوي للكروت
- ✅ تغذية كروت الباقات
- ✅ إدارة الباقات
- ✅ سجل المبيعات
- ✅ العملاء
- ✅ المحافظ
- ✅ أرشيف الرسائل
- ✅ نقاط البيع
- ✅ نسخ احتياطي واستعادة
- ✅ الإعدادات

## البيانات

كل البيانات محفوظة محلياً في المتصفح (LocalStorage).

---

## الخطوات التالية للنظام الكامل

### 1. جسر الرسائل (SMS Bridge)
تطبيق أندرويد يقرأ رسائل التأكيد من فودافون كاش / أورانج / إلخ ويرسلها للسيرفر.

### 2. السيرفر (Backend)
- استقبال رسائل التأكيد
- مطابقة المبلغ مع الطلبات المعلقة
- إرسال الكارت أوتوماتيك عبر واتساب

### 3. واجهة العميل
- بوت واتساب أو تطبيق بسيط يختار منه العميل الباقة ويرسل الفلوس.
